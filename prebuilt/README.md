# Prebuilt engine libraries

Build Cocos2d-x once for each target and configuration, then link the resulting
engine library from multiple game projects. This avoids rebuilding the engine
and its third-party dependencies whenever game code changes.

## Supported platforms

| Platform | Status |
| --- | --- |
| macOS | Supported |
| Android | Supported |
| Windows | Work in progress |

## Build a Debug library

Run these commands from the Cocos2d-x root.

macOS for the host architecture:

```sh
./prebuilt/build-prebuilt.sh \
  --platform macosx \
  --arch "$(uname -m)" \
  --config Debug
```

Android arm64:

```sh
./prebuilt/build-prebuilt.sh \
  --platform android \
  --arch arm64-v8a \
  --api 24 \
  --config Debug \
  --ndk "$ANDROID_NDK_HOME"
```

Repeat the Android command for each ABI the game ships. Use
`--config Release` when creating release libraries.

The script requires a POSIX shell and currently supports macOS builds and
Android cross-compilation. Windows support will use a native Windows
entrypoint when implemented.

## Use the library from a game

Projects generated by `cocos new -l cpp` use prebuilt engine libraries by
default on macOS and Android. The project locates the Cocos2d-x checkout in this
order:

1. `COCOS2DX_ROOT_PATH` passed to CMake or Gradle
2. the `COCOS2DX_ROOT` environment variable
3. an optional project-local `cocos2d` directory or symlink
4. one unambiguous nearby `cocos2d-x` checkout

No engine source is copied into a generated project. If the required library is
missing, the first game build creates it automatically.

Set `COCOS2DX_BUILD_PREBUILT_IF_MISSING=OFF` to require an explicit prebuilt
library. Set `COCOS2DX_ENGINE_MODE=SOURCE` to compile the engine as part of the
game project.

## Output

Libraries are written under:

```text
prebuilt/macosx/build/<arch>-<config>/lib/
prebuilt/android/build/<abi>-<config>/lib/
```

Generated build output is ignored by Git.

The Android prebuilt step needs the NDK for the compiler and platform headers.
The Android SDK and JDK are used later by Gradle when packaging the game.
